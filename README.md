# Thriftesque concept

Concept website for Thriftesque, a secondhand clothing shop in Qatar. Built by Nuvai Solutions.

- Photo catalogue of one-of-one pieces with category, size and sort filters
- Bag that sends the order as a prefilled WhatsApp message
- Team dashboard mockup (footer link, or `/#dashboard`) for adding and managing products

Single static file (`index.html`) with photos embedded. Deploys to Vercel with no build step.

Sample photos: CC0 clothing dataset (alexeygrigorev/clothing-dataset-small).
